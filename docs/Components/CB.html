M1

财务健康度与估值体系（承保 + 投资复利模型）

拆解有形账面价值（TBVPS）持续复利增长机制与 P/TBV 估值溢价合理性

为什么市场给予 Chubb 持续 P/TBV 估值溢价？

P/TBV ~1.9x
1. 高质量 ROTE 支撑估值锚（Gordon Growth 模型） ROTE ~21.5%

根据金融股经典估值公式 P/TBV = (ROTE - g) / (COE - g)，在股本成本（COE）约 9.5%、长期内生增长率 g 约 4.5% 的假设下，21.5% 的可持续 ROTE 对应合理 P/TBV 估值高达 2.0x–2.2x，显著高于 ROTE 仅 11%–14% 的 AIG（~1.1x）与 Travelers（~1.6x）。

2. 卓越的巨灾损失（CAT Losses）吸收与再保缓冲 标普 AA 评级

即便在北美飓风及全球严重对流风暴（SCS）高发年份，Chubb 凭借严格的单一地域风险敞口限额与多层巨灾再保安排，将巨灾损失对综合成本率的拖累控制在 3.5–4.5 个百分点以内，从未出现年度承保亏损。

3. 股东回报纪律：股息贵族 + 逆周期股票回购 年化回购 ~$2.5B+

连续 31 年上调现金股息（股息率 ~1.4%），同时每年利用超额自由资本回购约 2%–2.5% 流通股，持续增厚每股核心营业收益（Core Operating EPS）与每股有形净资产（TBVPS）。

四大核心下行风险深度剖析与风控缓释

1. 气候变化导致的极端巨灾（CAT）频发风险 核心行业风险

全球变暖导致北美飓风、严重对流风暴（SCS）及山火发生频率与单次损失金额上升，可能引发单季巨灾赔付超预算。缓释机制：Chubb 每年动态重估巨灾模型并持续上调高风险地区保费与免赔额，同时高度分散的全球地域组合有效平滑单一区域冲击。

2. 社会通胀（Social Inflation）与长尾责任险准备金补提 中高关注

美国司法诉讼激进度上升、陪审团天价判赔（Nuclear Verdicts）及医疗通胀推高了商业责任险（Casualty）理赔成本。缓释机制：Chubb 连续多年保持正向准备金释放（Favorable Prior Period Development），精算准备金计提历来显著保守于同业。

3. 降息周期对浮存金再投资收益率的边际影响 利率敏感度

若未来无风险利率大幅回落，新购固定收益债券的再投资票息将有所下移。缓释机制：由于当前投资组合账面平均收益率（约 4.6%）仍低于现行市场新购收益率（5.1%+），即便小幅降息，未来 18–24 个月内 NII 仍具正向抬升惯性。

4. 亚洲业务整合及新兴市场汇率/监管波动 跨境运营风险

控股华泰保险集团及拓展亚太寿险业务受当地偿付能力监管、资本跨境流动及亚洲货币汇率波动影响。缓释机制：亚洲多国布局高度分散，且 Chubb 拥有丰富的跨国险企合规治理经验。
